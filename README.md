# LAYLA — لعبة رعب نفسية عربية

لعبة رعب ثلاثية الأبعاد تعمل داخل المتصفح، ومهيأة للنشر عبر GitHub Pages.

## النسخة الحالية: Prototype 0.2
- حوش بيت عراقي قديم بإضاءة ليلية.
- غرفة استقبال داخلية بأثاث وسجادة وخزانة وسرير.
- منظور الشخص الأول.
- تحكم لمس للموبايل وتحكم بالفأرة للكمبيوتر.
- مصباح يدوي قابل للتشغيل والإطفاء.
- مفتاح يفتح الباب الرئيسي.
- صورة قديمة قابلة للفحص.
- ظهور ظل غامض بعد فحص الصورة.
- واجهة محادثة عربية تجريبية مع ليلى.

## التشغيل
افتح الموقع عبر GitHub Pages. يحتاج المتصفح إلى اتصال إنترنت لتحميل Three.js من jsDelivr وخط Cairo من Google Fonts.

## تفعيل GitHub Pages
من المستودع افتح **Settings → Pages**، ثم اختر **GitHub Actions** كمصدر للنشر. يوجد Workflow داخل `.github/workflows/pages.yml` ينشر محتويات المستودع عند كل تحديث على الفرع `main`.

## التحكم
- الهاتف: عصا التحكم للحركة، اسحب على الجهة اليمنى لتغيير اتجاه النظر، زر اليد للتفاعل.
- الكمبيوتر: انقر داخل المشهد لتفعيل تحكم الفأرة، وحرّك الفأرة للنظر.

## ملاحظات
هذه نسخة أولية قابلة للتطوير. المجسمات الحالية مولدة برمجياً وليست الأصول النهائية.
