# LAYLA — لعبة رعب نفسية عربية

تجربة رعب ثلاثية الأبعاد تعمل داخل المتصفح، وتُستضاف عبر GitHub Pages.

## النسخة الحالية: Prototype 0.1
- مشهد حوش بيت عراقي قديم مبني ثلاثي الأبعاد باستخدام Three.js.
- منظور الشخص الأول.
- تحكم باللمس على الهاتف وتحكم بالفأرة على الكمبيوتر.
- مصباح يدوي.
- مفتاح وباب قابل للتفاعل.
- واجهة محادثة تجريبية مع ليلى.
- واجهة عربية RTL.

## التشغيل
افتح الموقع عبر GitHub Pages. يحتاج المتصفح إلى اتصال إنترنت لتحميل Three.js من jsDelivr وخط Cairo من Google Fonts.

## النشر على GitHub Pages
من المستودع افتح **Settings → Pages**، ثم اختر **Deploy from a branch**، وحدد الفرع `main` والمجلد `/(root)` ثم Save.

المشروع واجهة أمامية ثابتة ولا يحتاج خادماً خلفياً.

## ملاحظات
